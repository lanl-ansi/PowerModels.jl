Quick Start Guide

This page provides a brief overview of the features of PowerModels.jl.

Setup

This page uses the following packages:

julia> using PowerModels
julia> using Ipopt

This page also uses various input files. In this build of the documentation, we use the files in:

julia> DATA_DIR = joinpath(pkgdir(PowerModels), "test", "data");

but there are many public instances that you can use, for example, by going to pglib-opf.

Solving the basic Optimal Power Flow

Once PowerModels is installed, Ipopt is installed, and a network data file (e.g., "case3.m" or "case3.raw") has been acquired, an AC Optimal Power Flow can be executed with:

Getting Results

The run commands in PowerModels return detailed results data in the form of a dictionary. Results dictionaries from either Matpower .m or PTI .raw files will be identical in format. This dictionary can be saved for further processing as follows,

julia> result = solve_ac_opf(
           joinpath(DATA_DIR, "matpower", "case3.m"),
           optimizer_with_attributes(Ipopt.Optimizer, "print_level" => 0),
       )Dict{String, Any} with 8 entries:
  "objective_lb"       => -Inf
  "termination_status" => LOCALLY_SOLVED
  "objective"          => 5906.88
  "primal_status"      => FEASIBLE_POINT
  "dual_status"        => FEASIBLE_POINT
  "optimizer"          => "Ipopt"
  "solve_time"         => 0.00510311
  "solution"           => Dict{String, Any}("baseMVA"=>100.0, "multinetwork"=>f…

For example, the algorithm's runtime and final objective value can be accessed with:

julia> result["solve_time"]0.005103111267089844
julia> result["objective"]5906.879416718175

Accessing Different Formulations

The functions solve_ac_opf and solve_dc_opf are shorthands for a more general formulation-independent OPF execution, solve_opf. For example, solve_ac_opf is equivalent to:

julia> solve_opf(
           joinpath(DATA_DIR, "matpower", "case3.m"),
           ACPPowerModel,
           optimizer_with_attributes(Ipopt.Optimizer, "print_level" => 0),
       )Dict{String, Any} with 8 entries:
  "objective_lb"       => -Inf
  "termination_status" => LOCALLY_SOLVED
  "objective"          => 5906.88
  "primal_status"      => FEASIBLE_POINT

  "optimizer"          => "Ipopt"
  "solve_time"         => 4.54527
  "solution"           => Dict{String, Any}("baseMVA"=>100.0, "multinetwork"=>f…

where ACPPowerModel indicates an AC formulation in polar coordinates. This more generic solve_opf() allows one to solve an OPF problem with any power network formulation implemented in PowerModels. For example, an SOC Optimal Power Flow can be run with:

julia> pm = instantiate_model(
